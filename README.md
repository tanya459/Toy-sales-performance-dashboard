# Toy Sales Performance Dashboard

An interactive Power BI dashboard designed to analyze toy sales performance, revenue generation, product performance, and profitability.

## Project Overview

This project presents an interactive sales analytics dashboard built using Microsoft Power BI.

The dashboard provides a consolidated view of toy sales performance through key business metrics and visualizations. It allows users to analyze revenue, product performance, category-level sales, weekday profitability, and revenue trends using interactive filters.

## Project Objective

The objective of this project is to analyze toy sales data and transform it into meaningful business insights using data cleaning, transformation, analysis, and visualization techniques.

The dashboard helps identify:

- Overall revenue performance
- Highest-performing products
- Revenue generated across product categories
- Units sold across categories
- Average profit by weekday
- Monthly revenue trends
- Performance based on region and year

## Tools & Technologies

## Dashboard Overview

The dashboard contains the following major components:

### 1. Revenue KPI

Displays the overall revenue generated based on the selected filters.

**Total Revenue:** 8.76M

### 2. Top 10 Highest Selling Products

A ranking of the highest-revenue-generating products.

The dashboard shows **Dinosaur Figures** as the highest-performing product among the displayed products, generating approximately **4.3M** in revenue.

### 3. Units Sold vs Revenue

Compares the number of units sold with the total revenue generated across different product categories.

The categories include:

- Art & Craft
- Toys
- Games
- Sports & Outdoors
- Electronics

### 4. Average Profit by Weekday

Shows the average profit generated for each day of the week, helping identify variations in profitability across weekdays.

### 5. Latest Year Revenue Trend

Displays monthly revenue performance for the latest selected year.

The dashboard includes monthly revenue from **January to December** and highlights changes in revenue throughout the year.

### 6. Interactive Filters

The dashboard provides interactive filtering options for:

- Region
- Year

These filters allow users to explore the data based on different selections.

## Key Insights

Based on the dashboard:

- Total revenue displayed is **8.76M**.
- **Dinosaur Figures** is the highest-revenue-generating product shown, with approximately **4.3M** revenue.
- **Toys** is one of the major contributing product categories.
- Revenue shows a noticeable increase during **October and November** in the latest-year trend.
- Average profit varies across different weekdays.
